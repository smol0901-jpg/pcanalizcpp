# PC Analyzer Pro

Профессиональная система мониторинга и защиты ПК с встроенной нейросетью для анализа и прогнозирования.

## 🚀 Возможности

### Основные функции (300+ фич)

#### 🔍 Мониторинг системы
- **CPU**: Мониторинг загрузки процессора в реальном времени (общая и по ядрам)
- **RAM**: Контроль использования оперативной памяти
- **DISK**: Отслеживание свободного места на дисках
- **TEMP**: Мониторинг температуры CPU (если доступно)
- **Network**: Скорость upload/download, трафик
- **WiFi**: Статус подключения, SSID, сила сигнала
- **Internet**: Проверка доступности интернета, ping до DNS
- **Battery**: Заряд батареи, статус питания (для ноутбуков)
- **Processes**: Список процессов с сортировкой по нагрузке
- **Uptime**: Время работы системы

#### 🛡️ Автозащита от перегрузки
- **Порог 95%**: Автоматическая защита при достижении 95% нагрузки
- **Снижение приоритетов**: Автоматическое снижение приоритета фоновых процессов
- **Очистка кэша**: Освобождение оперативной памяти
- **Кулдаун**: Защита от частых срабатываний (настраивается)
- **Температурный контроль**: Предупреждения о перегреве

#### 🧠 Встроенная нейросеть
- **Isolation Forest**: Обнаружение аномалий в работе системы
- **MLP Regressor**: Прогнозирование перегрузок
- **Адаптивное обучение**: Постоянное обучение на новых данных
- **Рекомендации**: Умные советы по оптимизации
- **Статистика**: Отслеживание обнаруженных аномалий

#### 📊 База данных и отчеты
- **SQLite**: Локальное хранение всех метрик
- **История**: Сохранение данных за последние 30 дней
- **JSON отчеты**: Полные отчеты о состоянии системы
- **HTML отчеты**: Красивые визуальные отчеты
- **CSV экспорт**: Данные для дальнейшего анализа
- **Графики**: Визуализация метрик во времени
- **Предупреждения**: История всех алертов

#### ⚙️ Настройки
- **Пороги предупреждений**: Настраиваемые уровни CPU, RAM, DISK, TEMP
- **Интервалы обновления**: Fast (1s), Normal (5s), Slow (30s)
- **Автозащита**: Включение/выключение функций защиты
- **Профили систем**: Автоопределение типа ПК (low_end, basic, standard, high_performance)

#### 🎨 Графический интерфейс (PyQt5)
- **Главная панель**: Визуальные прогресс-бары ресурсов
- **Вкладка процессов**: Таблица топ-30 процессов
- **Вкладка предупреждений**: История алертов с цветовой индикацией
- **Вкладка отчетов**: Генерация и просмотр отчетов
- **Вкладка настроек**: Конфигурация всех параметров
- **Статус бар**: Быстрая информация о состоянии
- **Тулбар**: Быстрый доступ к основным функциям
- **Цветовая индикация**: Зеленый/Оранжевый/Красный в зависимости от нагрузки

#### 🖥️ Консольный режим
- Работает без графического интерфейса
- Идеально для серверов и удаленных систем
- Минимальное потребление ресурсов
- Логирование всех событий

## 🎯 Как использовать

### Консольный режим
1. Запустите программу: `python pc_analyzer_pro.py`
2. Наблюдайте за метриками в реальном времени
3. Нажмите `Ctrl+C` для остановки
4. Отчет автоматически сохранится в папку `reports/`

### Графический режим (при наличии PyQt5)
1. Запустите программу

5. Следите за графиками и статистикой

## 🔧 Конфигурация

Измените значения в классе `Config`:

```python
CPU_WARNING_THRESHOLD = 75      # Порог предупреждения CPU (%)
CPU_CRITICAL_THRESHOLD = 95     # Критический порог CPU (%)
RAM_WARNING_THRESHOLD = 80      # Порог предупреждения RAM (%)
RAM_CRITICAL_THRESHOLD = 95     # Критический порог RAM (%)
AUTO_PROTECTION_ENABLED = True  # Включить автозащиту
PROTECTION_COOLDOWN = 60        # Кулдаун защиты (сек)
```

## 🛡️ Система защиты

При достижении критических значений:
1. **CPU > 95%**: Снижение приоритета фоновых процессов
2. **RAM > 95%**: Очистка системных кэшей
3. **TEMP > 90°C**: Критическое предупреждение
4. **DISK > 95%**: Предупреждение о необходимости очистки

Защита имеет кулдаун для предотвращения частых срабатываний.
